# Portal BPPK Baru

Saya sedang merancang website untuk BPPK. Saya sudah membuat HTML-nya, namun ingin disempurnakan lagi untuk desainnya. Saya juga punya visual guideline untuk desain media sosial, Rencananya akan mengikuti guideline tersebut. Saya juga membuat 3 gambar untuk nantinya bisa dijadikan sampel untuk hero-nya. Semoga lampirannya bisa membantu. Untuk desain awalnya juga sudah saya lampirkan dalam html dan gambar.

Pada menu navigasi atas, saya ingin ketika di-scroll nanti dari awalnya seperti gelas menjadi warna yang solid. 
kemudian, untuk bagian floating card di bawah Hero, saya ingin ketika kartu terkena hover, dua akan memanjang ke atas menampilkan deskripsi dan berlatar gambar.
Lalu untuk card pelatihan dan berita, saya ingin ketika di-hover, seluruh kartu menjadi full gambar sebagai latar.
Pada bagian literasi ada majalah, jurnal, dan buku, Saya ingin dia seperti gulungan yang berjejer sehingga ketika di-hover dia akan melebar ke samping.

Kurang lebih seperti itu, semoga bisa dipahami. terimakasih
